## 🚫 What DIDN'T Change (Intentionally)

These remain as `nexora` to avoid breaking internal infrastructure:

❌ **GitHub repository name**: `nexora-ai` (stays the same)
❌ **Local folder name**: `nexora-ai` (stays the same)
❌ **localStorage keys**: `nexora_jwt`, `nexora_user`, etc. (internal, users don't see)
❌ **Console log messages**: References to "Nexora" in developer console (doesn't affect users)
❌ **Function names**: Internal code variable names (doesn't affect users)

**Why?** These are internal infrastructure that users never see. Changing them would require:
- Renaming GitHub repo (breaks links, stars, forks)
- Updating all git remotes
- Migrating user data in localStorage
- Potential bugs and data loss

**Not worth it!** The brand name is what matters to users, not the backend plumbing.
