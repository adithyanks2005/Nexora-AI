# How to Submit Your is-a.dev Pull Request

## 📝 You have the domain config file ready!

File created: `domains-medicura-ai.json` in your project folder.

---

## 🚀 Step-by-Step: Submit the PR

### 1. Go to your forked repository

Visit: **https://github.com/adithyanks2005/register**

(This should be your fork of `is-a-dev/register`)

---

### 2. Upload the domain config file

**In your fork:**

1. Click **"Add file"** → **"Upload files"**
2. Navigate to the `domains` folder (click on "domains" folder first)
3. Click **"Add file"** → **"Upload files"** again
4. Drag `domains-medicura-ai.json` from your project folder
5. **IMPORTANT:** Rename it to just **`medicura-ai.json`** (remove "domains-" prefix)
6. Commit message: "Add medicura-ai.is-a.dev domain"
7. Click **"Commit changes"**

---

### 3. Create the Pull Request

1. Go to: **https://github.com/is-a-dev/register/compare**
2. Click **"compare across forks"**
3. Set:
   - **base repository:** `is-a-dev/register`
   - **base:** `main`
   - **head repository:** `adithyanks2005/register` (your fork)
   - **compare:** `main`
4. Click **"Create pull request"**

---

### 4. Fill in PR details

**Title:**
```
Add medicura-ai.is-a.dev
```

**Description:**
```
Requesting medicura-ai.is-a.dev subdomain for MediCura AI healthcare assistant.

- Site: MediCura AI - Free AI Healthcare Assistant
- Type: Healthcare web application
- Owner: @adithyanks2005
- Email: ksadithyan2021@gmail.com
- Current URL: https://nexora-ai-flax.vercel.app
- New domain: medicura-ai.is-a.dev
- CNAME: cname.vercel-dns.com (Vercel deployment)

MediCura AI is a free, open-source healthcare assistant that provides:
- AI health chat
- Symptom checker
- Health calculators (BMI, calories, water intake)
- Medication reminders
- Health record tracking

Thank you for reviewing!
```

5. Click **"Create pull request"**

---

### 5. Wait for approval

- ⏰ **Timeline:** 1-3 days
- 📧 **Notification:** You'll get an email at `ksadithyan2021@gmail.com`
- ✅ **Status:** Check your PR for comments from maintainers

---

## 📧 What to expect via email

You'll receive:

1. **GitHub notification:** "Your pull request was mentioned in..."
2. **Approval notice:** When a maintainer approves
3. **Merge notification:** When PR is merged (domain is live!)

---

## ⏭️ After PR is approved

**Come back to `QUICK_START_GUIDE.md` and continue from Step 4** (Add domain to Vercel)

---

## ❓ Common Questions

**Q: What if I can't find my fork?**  
A: Go to https://github.com/adithyanks2005?tab=repositories and look for "register"

**Q: What if the file is already named correctly?**  
A: Perfect! Just make sure it's in the `domains/` folder as `medicura-ai.json`

**Q: What if they ask for changes?**  
A: Just reply to the PR comment and make the requested changes. Common requests:
- Fix typo in email
- Verify CNAME record
- Confirm you own the Vercel deployment

**Q: Can I check PR status?**  
A: Yes! Visit: https://github.com/is-a-dev/register/pulls and find your PR
